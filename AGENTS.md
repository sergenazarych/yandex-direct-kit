# Указания для Codex и других ассистентов

Это учебный набор для работы с Яндекс Директом. Пользователь — ученик курса,
он директолог или маркетолог, не программист. Общайтесь по-русски.

Скиллы лежат в `.claude/skills/` (формат Claude Code). Если ваш ассистент не подключает их сам,
определите по запросу нужный скилл, прочитайте его `SKILL.md` и следуйте ему.
Пути внутри скилла указаны относительно его папки.

| Скилл | Когда использовать |
|---|---|
| `.claude/skills/yandex-direct/SKILL.md` | API Директа и Wordstat: статистика, кампании, фразы, площадки, загрузка кампании из таблицы |
| `.claude/skills/pasport-proekta/SKILL.md` | паспорт проекта, бриф, портрет клиента, сегменты, нецелевой спрос |
| `.claude/skills/vybor-strategii-zapuska/SKILL.md` | выбор стратегии запуска: квиз, лендинг, лид-магнит, подписная; МК, РСЯ или поиск |
| `.claude/skills/auditor-posadochnyh/SKILL.md` | аудит посадочной, «почему не конвертит» |
| `.claude/skills/usilitel-pervogo-ekrana/SKILL.md` | заголовок, оффер, первый экран лендинга, концепции для A/B-теста |
| `.claude/skills/seo-teg-podskazki/SKILL.md` | title, description, H1 и ключевые слова страницы как подсказка Директу |
| `.claude/skills/rsya-creative-prompts/SKILL.md` | промпты для картинок РСЯ |

Правила:
- Ученик просит начать или продолжить настройку («начни настройку», «продолжим»)
  или в `my/progress.md` есть незавершённые этапы: работайте по [ONBOARDING.md](ONBOARDING.md).
- Материалы по проекту храните в `my/<проект>/`, паспорт — файлом `my/<проект>/pasport-<клиент>.md`.
  Прежде чем спрашивать ученика о проекте, поищите ответ там.
- Секреты не проходят через чат. Файл `.claude/skills/yandex-direct/config/.env` не открывайте
  и не выводите. Токены и ключи ученик вставляет туда сам, в редакторе.
- Команды Директа ходят в интернет (api.direct.yandex.com, searchapi.api.cloud.yandex.net). Если песочница
  их блокирует, попросите ученика разрешить сетевой доступ для этих команд.
- В кабинет ничего не пишется без явного «да» ученика после показанного плана (`--apply`).
- Файлы скиллов меняйте, только если ученик просит.

# Как собрать и очистить пул

## Матрицы

Для «ремонта пластиковых окон» попробуй действие × объект («починить окно»), исполнитель × специализация («мастер по окнам»), симптом × объект («дует из окна»), отдельные работы («замена уплотнителя»). Цена, вызов, район служат уточнениями. Начни с короткой осмысленной маски, добавь обязательный модификатор там, где без него меняется предмет покупки. Например, «замена масла» имеет смысл, а перемножение «замена × Toyota» без указания работы даёт другой спрос. Проверяй несколько сочетаний до массовой выгрузки. Слишком длинная матрица с городом и коммерческим словом в каждой строке теряет людей, которые ищут ту же услугу проще.

Новую специализацию, необычный синоним или способ описать проблему добавь новой маской и проверь вложения. Для слова «мастер» выясни, ищут ли выезд специалиста, вакансию или обучение. Словоформы и перестановки без изменения смысла обычно не требуют отдельных веток. При спорном смысле проверь региональную выдачу и несколько запросов с уточнениями. Сохрани причину классификации. Достаточное покрытие — проверены существенные услуги и синонимы из брифа, а очередной проход по вложениям и ассоциациям не открывает новой уместной ветки. Зафиксируй неохваченные маски при ограничении квоты.

## Получение частот через yandex-wordstat

В ученическом наборе из каталога yandex-direct выполни `uv run scripts/wordstat.py top --phrase "монтаж потолков" --region 213 --limit 100`. Сохрани вывод со строкой «всего запросов», вложениями и похожими запросами. Ключ `--csv` экспортирует только вложения. Для кавычечного замера передай выражение с кавычками внутри значения `--phrase`. Динамику получай через `wordstat.py dynamics`. На компьютере ученика без uv вместо `uv run` используй команду Python из ONBOARDING.md. Если установлен отдельный yandex-wordstat, используй команды ниже. Запускай команды из каталога соответствующего API-скилла. Примеры для Bash, ID региона 213 условный.

```bash
bash scripts/search_region.sh --name "Москва"
bash scripts/quota.sh
bash scripts/top_requests.sh --phrase "ремонт окон" --regions 213 --devices all --limit 500 --csv "/path/to/project/windows.csv"
bash scripts/query_total.sh --phrase 'ремонт окон' --regions 213
bash scripts/query_total.sh --phrase '"ремонт окон"' --regions 213
```

Путь экспорта замени абсолютным путём проекта. `top` даёт вложенные запросы, `assoc` — соседние идеи. Сохраняй полную выгрузку и ограничения выборки. Если упёрся в лимит выдачи, уточни ветку новой маской. Для перспективных и двусмысленных фраз сравни базовую и кавычечную частоту при одинаковых регионе, устройствах и периоде. Укажи дату получения, доступный период данных и точное выражение с операторами. Пересекающиеся маски описывают общий спрос частично повторно. Не складывай их показы как уникальный прогноз. Изменение частоты по месяцам и сезонность проверь через `dynamics.sh` на поддерживаемом выражении. Для месячной динамики клиент поддерживает только оператор `+` из операторов уточнения. [Операторы Вордстата](https://yandex.ru/support2/wordstat/ru/content/operators).

Большая базовая частота при маленькой кавычечной — повод проверить, где сидит спрос во вложениях. «Квартира с ремонтом» и «заказать ремонт квартиры» могут относиться к разным покупкам. Большая частота постороннего вложения не делает исходную маску хорошим ключом. Нулевое число для конкретной формы не доказывает отсутствие спроса на услугу. Когда прямой спрос мал, проверь сезон, варианты названия и размер региона. Расширять географию можно только в пределах возможностей клиента.

## Операторы и минусование

В рабочей фразе кавычки фиксируют количество слов, `!` — форму слова, `+` — значимое стоп-слово, `[]` — порядок слов внутри скобок. Это разные решения. Разделяй оператор, использованный при измерении спроса, и выражение, предлагаемое к загрузке. Применяй ограничение там, где оно сохраняет смысл, например направление маршрута. Приём из интенсива со скобками вокруг важного уточнения («оптом», «дистанционно») помечай как эксперимент с контролем фактических запросов, расхода и целевых обращений. Не приписывай скобкам свойство гарантированно устранять семантическое расширение. [Операторы Директа](https://yandex.ru/support/direct/ru/keywords/symbols-and-operators).

Разметь запросы как принять, тестировать, отложить, исключить. Отдельно принимай решение о минусе. «Не брать ключ» ещё не даёт основания запрещать каждое его слово. Для системного мусора запиши минимально достаточное слово или сочетание и пример исходного запроса. Определи область действия — фраза, группа или кампания. Для кампании потребуй применимость исключения ко всем её группам. Для групповой кросс-минусовки сначала убедись, что другая группа действительно примет ценный запрос. Отдельно проверь словоформы, предлоги, порядок и вложения. Например, для «работа мастером по ремонту окон» проверь минус-фразу группы или кампании `!работа !мастером`. Она сохраняет «стоимость работы мастера по ремонту окон». Более общий минус «работа» мог бы закрыть полезное вложение. На уровне ключа применяют отдельные минус-слова, на уровне группы/кампании — также сочетания. Если все слова минуса уже входят в ключ, Директ игнорирует пересекающийся минус. Проверь конкретную пару ключа и запроса. Поиск конфликтов делай с сохранением синтаксиса Директа. [Минус-слова и минус-фразы](https://yandex.ru/support/direct/ru/keywords/negative-keywords).

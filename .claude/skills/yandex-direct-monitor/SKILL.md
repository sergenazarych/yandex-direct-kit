# Мониторинг Яндекс Директа

Прочитай [настройку панели и расписания](references/setup.md). Скрипт использует уже настроенный в соседнем `yandex-direct` доступ и только читает Директ. Для ученика собери `my/direct-monitor/settings.json` на основе [образца](assets/settings.example.json), проверь доступ к названным кабинетам и запусти первую выгрузку. Если кабинетов доступно несколько, используй только те, которые ученик выбрал.

Для разбора РСЯ используй соседний `yandex-direct-rsya-optimization`. Подготовку, согласование и запись корректировок веди через него. При запросе регулярной сводки настрой расписание на платформе ученика после успешной первой выгрузки. [Инструкция для регулярной сводки](references/monitoring.md).

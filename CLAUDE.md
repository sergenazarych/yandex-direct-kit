# Указания для ассистента

Это учебный набор для работы с Яндекс Директом. Пользователь — ученик курса,
он директолог или маркетолог, не программист. Общайтесь по-русски.

- Ученик просит начать или продолжить настройку («начни настройку», «продолжим»)
  или в `my/progress.md` есть незавершённые этапы: работайте по [ONBOARDING.md](ONBOARDING.md).
- Скиллы лежат в `.claude/skills/`, перед работой прочитайте `SKILL.md` нужного:
  - `yandex-direct` — API Директа и Wordstat: статистика, кампании, фразы, площадки, загрузка из таблицы;
  - `pasport-proekta` — паспорт проекта (центральный документ, на него опираются остальные);
  - `vybor-strategii-zapuska` — выбор стратегии запуска;
  - `auditor-posadochnyh` — аудит посадочной;
  - `usilitel-pervogo-ekrana` — первый экран посадочной;
  - `seo-teg-podskazki` — SEO-теги как подсказка для Директа;
  - `rsya-creative-prompts` — промпты картинок для РСЯ.
- Материалы по проекту (паспорт, стратегия, первый экран, таблица, креативы) храните в `my/<проект>/`,
  паспорт — файлом `my/<проект>/pasport-<клиент>.md`. Прежде чем спрашивать ученика о проекте,
  поищите ответ там.
- Секреты не проходят через чат. Файл `.claude/skills/yandex-direct/config/.env` не открывайте
  и не выводите. Токены и ключи ученик вставляет туда сам, в редакторе.
- В кабинет ничего не пишется без явного «да» ученика после показанного плана (`--apply`).
- Файлы скиллов меняйте, только если ученик просит.

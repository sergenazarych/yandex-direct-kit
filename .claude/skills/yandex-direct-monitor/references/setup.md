# Как включить панель Директа

## Первый запуск

Откройте папку репозитория в Claude Code или Codex и напишите «Настрой панель Директа для кабинета `мой-логин`». Достаточно подключённого API Директа. Wordstat, браузерный вход для ночной задачи и создание новой кампании для панели не требуются.

1. Проверьте подключение по [инструкции ученика по API](../../yandex-direct/config/STUDENT_GUIDE.md). Учётные данные храните в `config/.env` скилла `yandex-direct`.
2. Создайте `my/direct-monitor/settings.json` копированием [примера настроек](../assets/settings.example.json). Впишите логин кабинета Директа, название для панели и валюту. Несколько кабинетов добавьте отдельными объектами в `accounts`. `campaign_ids: []` включает все кампании выбранного кабинета. `report_goals: {}` берёт цели стратегий кампаний. Чтобы везде смотреть по конкретной цели, укажите, например, `"report_goals": {"123456789": "Заявка"}` с вашим действительным ID. CPC по умолчанию сравнивается с порогами 10 и 100 в валюте кабинета, их можно настроить в JSON или в панели.
3. Запустите из корня репозитория при помощи Python 3.11 или новее:

   ```sh
   python3 .claude/skills/yandex-direct-monitor/scripts/refresh.py --backfill
   ```

   На Windows используйте `py -3` вместо `python3`. Для проверки логина отдельно запустите `python3 .claude/skills/yandex-direct/scripts/whoami.py --account ЛОГИН` с логином из настроек.
4. Откройте `my/direct-monitor/dashboard.html` в браузере. Проверьте кабинет, выбранную цель и даты. Сверьте расход с Директом за тот же период и с теми же настройками НДС и трафика. Селектор «Весь трафик» включает поиск и сети, «Только РСЯ» показывает статистику сетевого трафика.

## Регулярное обновление

Попросите Codex «Обновляй эту панель и присылай сводку в 08:00 по Москве, а в 00:00 сохраняй остатки кабинетов». Ассистент использует встроенные Automations, если они доступны, и [инструкцию для регулярной сводки](monitoring.md). Локальная задача зависит от доступности компьютера, сети и Codex. Отчёт за месяц обновляется первого числа, за неделю — по понедельникам. При первом запуске `--backfill` сразу добавляет оба периода.

Для запуска через локальный планировщик компьютера укажите папку репозитория как рабочую и используйте команды выше без `--backfill`. Для отдельного замера в полночь добавьте `--balance-only`. Панель готовит скрипт, текстовую сводку и рекомендации можно поручить ассистенту. Если ассистент внесёт заметки в `notes.json`, команда `--render` обновит интерфейс без веб-запросов.

Файлы `settings.json`, `dashboard.html`, журналы API, история расходов и заметки находятся в папке `my/`, которую Git игнорирует. Для каждого отдельного проекта можно передать `--settings my/<проект>/settings.json`. По умолчанию панель и данные сохраняются рядом с этим файлом. Не публикуйте эту папку вместе с учебным набором.

## Как читать панель

- По умолчанию «Все цели» показывает сумму достижений выбранных для отчёта целей. Один человек может выполнить несколько целей. Чтобы увидеть статистику одной цели, выберите её в списке. Если Директ вернул данные только по части целей, панель показывает подтверждённые конверсии и оставляет общий CPA и CR пустыми. Показатели относятся к выбранному периоду и типу трафика.
- Если остаток доступен, панель показывает точное время замера. Остаток на начало дня появляется при замере около полуночи.
- Площадки, объявления, форматы, возраст, устройства и география сортируются по столбцам. Фильтры показывают подозрительно дешёвые или дорогие клики, высокий CPA и расход без конверсий. Один сигнал требует проверки объёма и состава трафика перед изменением кампании.
- Для отдельных заголовков, текстов и картинок нужен отчёт по сочетаниям из Мастера отчётов. Публичный API даёт статистику объявлений и форматов, а для части кампаний Мастера кампаний — только сводные строки без номера объявления.

# Плановый отчёт по Директу

После первой успешной выгрузки проверь, что локальная задача запускается из папки репозитория, видит Python 3.11+, настройки ученика и уже настроенный OAuth. В Codex используй штатные Automations. Передай задаче полный путь репозитория и к этому файлу. Используй московское время, на нём построены отчётные периоды в скрипте.

## Остаток с утра

В 00:00 МСК запусти `python3 .claude/skills/yandex-direct-monitor/scripts/refresh.py --balance-only`. На Windows подходит `py -3`. Первый замер с 00:00 по 00:14 МСК показывается как остаток на начало дня. При отсутствии ночной записи показывай последнее значение с фактическим временем. Если API не вернул баланс общего счёта, назови причину, когда она доступна. Расходы дня не восстанавливают исторический баланс.

## Сводка за день, неделю и месяц

1. В 08:00 МСК запусти `python3 .claude/skills/yandex-direct-monitor/scripts/refresh.py`. Обычный запуск получает данные за вчера. По понедельникам он добавляет прошедшую неделю и сравнение с предыдущей, первого числа — прошедший месяц и сравнение с предыдущим. Укажи даты свежих периодов. При частичном сбое назови кабинеты и разрезы, которые не удалось обновить.
2. Прочитай `my/direct-monitor/latest.json`. `accounts[логин]` содержит весь трафик, `accounts[логин].network` — сети. Сверяй значения по одному кабинету, периоду, трафику, НДС, цели и модели атрибуции. По неполной или недоступной цели оставляй пропуски. Не суммируй конверсии разных целей. Сравнивай расход, клики, цену клика, конверсии, долю и стоимость конверсии. Для свежих дат явно учитывай догрузку конверсий.
3. Разбери `alerts`: сравнение с обычным значением за предыдущие 28 дней учитывает размер выборки. Назови результат просто, например «В кампании „Каталог“ цена клика выросла с 25 ₽ до 40 ₽. Посмотрите, какие площадки привели больше трафика». Уточни, относится ли сигнал ко всему трафику или к РСЯ. Для РСЯ используй [методику урока](../../yandex-direct-rsya-optimization/references/analysis.md). Сигнал расхода выше 3 CPA требует подтверждённого нуля конверсий. Фильтры дорогих заявок сравнивают цену конверсии с 2× или 3× среднего уже при одной конверсии. При одной или двух отметь небольшой объём данных. Эти сигналы требуют проверки до корректировок.
4. Запиши пояснения в `my/direct-monitor/notes.json` как `логин → дата запуска → all или network → day, week, month → список коротких строк`. Сохраняй прежние записи. Обнови итоговый HTML командой `python3 .claude/skills/yandex-direct-monitor/scripts/refresh.py --render`. Дай ученику сводку и ссылку на `my/direct-monitor/dashboard.html`. Свежие оплачиваемые рекомендации оформляй для согласования через `yandex-direct-rsya-optimization`.

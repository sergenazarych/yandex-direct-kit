# Библиотека элементов: шрифты, цвета, плашки, кнопки

Снято с 33 референсов автора (К-01…К-33). В промпте называй элемент словами этой библиотеки: тип шрифта, цвет, форму плашки, цвет и форму кнопки. Надписи в оригиналах местами строчные; в промптах всё пишется ЗАГЛАВНЫМИ (см. rules.md).

### 3.1 Шрифты заголовка (по виду)
- **Узкий плотный гротеск (condensed, bold)**, ВЕРХНИЙ РЕГИСТР, как DIN Condensed / Bebas Neue / Oswald: К-01, К-02, К-04, К-05, К-06, К-07, К-08, К-12, К-17. Это базовый «рабочий» стиль: компактно, много текста в узком столбце.
- **Широкий жирный гротеск (extended / black)**: К-03, К-09, К-10, К-13, К-19, К-20. Крупно, «орёт», подходит для коротких фраз.
- **Классическая антиква с засечками**: К-14, под гравюру и мистику.
- **Декоративная орнаментальная** (буквы вплетены в сцену): К-15.
- **Нейтральный средний гротеск (regular/medium)**: К-16, К-18 для подзаголовков и плашек.

Всегда ВЕРХНИЙ РЕГИСТР в заголовке, кроме подзаголовков в К-16 (обычный регистр).

### 3.2 Цвет текста
- Белый на тёмном/цветном фоне (К-01, К-04, К-05, К-06, К-08, К-16).
- Тёмно-синий/чёрный на светлом (К-02, К-03, К-09, К-12, К-13).
- **Акцентное слово другим цветом** (одно ключевое слово или строка): К-10 (зелёный «ОПТОВЫХ КОМПАНИЙ»), К-13 (синий «АВТОВОРОНКИ»), К-17 (оранжевый «КРИПТОДЕПОЗИТ»), К-11 (зелёный подзаголовок), К-20 (красное подчёркивание).
- Тёмный текст на жёлтой плашке — самый «кричащий» вариант (К-19, К-20).

### 3.3 Подложки под текст
| Тип | Где | Параметры |
|---|---|---|
| Сплошная полоса на всю ширину, полупрозрачная тёмная (~60–75%) | К-05, К-08 | Заголовок по центру, 3–4 строки |
| Скруглённая плашка цвета бренда | К-11 (синяя), К-07 (белая) | Радиус ~15–25 px, текст внутри с отступами |
| Белая прямоугольная плашка без скруглений | К-03, К-18 | Прямые углы, тёмно-синий/зелёный текст |
| Тёмная полупрозрачная плашка под часть текста | К-17 | Скруглённая, акцентное слово над ней |
| Жёлтый «стикер» с красной смещённой тенью, чуть повёрнут | К-19, К-20 | Контрастная обводка/тень, угол 2–4° |
| Нет подложки, текст прямо по фону | К-01, К-02, К-04, К-06, К-10, К-13, К-14, К-16 | Фон должен быть спокойным в зоне текста |

### 3.4 Кнопки (CTA)
Кнопка нарисована в изображении, она не реальная. Формулировки глагольные, ВЕРХНИЙ РЕГИСТР, 2–3 слова.

| Текст | Креатив | Форма | Цвет |
|---|---|---|---|
| СМОТРЕТЬ В ТЕЛЕГРАМ | К-04 | Скруглённый прямоугольник + нижняя смещённая тень темнее | Синий #0075C9 |
| СМОТРЕТЬ МАСТЕР-КЛАСС | К-07 | Скруглённый, лёгкая тень | Фиолетовый, белый текст |
| УЗНАТЬ ПОДРОБНЕЕ | К-08 | Сильно скруглённый | Зелёный |
| ЧИТАТЬ СТАТЬЮ | К-10, К-17 | Пилюля (pill) | Зелёная / белая с тёмным текстом |
| ПОДРОБНЕЕ | К-12 | Скруглённый, с тенью | Тёмно-синий |
| ПОЛУЧИТЬ СТАТЬЮ | К-13 | Скруглённый | Синий |
| ЗАПИСАТЬСЯ НА ИНТЕНСИВ | К-16 | Скруглённый | Бирюзово-мятный, тёмный текст |
| ЧИТАТЬ ИССЛЕДОВАНИЕ + иконка Telegram | К-19 | Скруглённый, чуть повёрнут | Синий, белый текст |

Кнопки стоят **под заголовком**, слева или по центру блока, ширина по тексту. Размер заметно меньше заголовка по кегль, но по контрасту это второй по заметности элемент.
Креативы **без кнопки**: К-01, К-02, К-03, К-06, К-14, К-15, К-18, К-20, К-09, К-11. Кнопка нужна не всегда, особенно если тема «шок/любопытство».

### 3.5 Служебные и доказательные элементы
- Пиктограммы выгод в плашке из 3 блоков (К-03).
- Скриншоты дашбордов, диаграмма-пончик, подпись эксперта (К-12).
- Скриншот банковского перевода (К-09).
- Логотип бренда внизу (К-18).
- Хештеги-районы на плашке (К-18).

# Яндекс Директ + нейросеть: набор для учеников

В этом репозитории собран готовый помощник для работы с Яндекс Директом из терминала.
Он подключается к API Директа и Wordstat, показывает статистику и загружает кампанию
из таблицы прямо в кабинет. Настраивать его вручную по инструкции не нужно:
откройте папку в Claude Code или Codex, и ассистент проведёт вас по шагам.

Набор продолжает уроки курса:
1. **«Структура кампании в РСЯ»**: по этому эталону собраны шаблон таблицы и проверки загрузчика.
2. **«Ключи API Директа и Wordstat»**: здесь этот урок проходится на практике.

## Что вы получите в конце

- Ключ к API Директа: ассистент видит ваши кампании и статистику.
- Ключ к Wordstat: частотность и динамика запросов прямо в терминале.
- Первую кампанию в РСЯ, загруженную из таблицы. Она создаётся черновиком,
  запускаете её вы сами.

## Что понадобится

| Что | Зачем |
|---|---|
| Яндекс-аккаунт с кабинетом Директа и хотя бы одной кампанией (подойдёт черновик) | без кампании заявку на API не подать |
| Аккаунт в Yandex Cloud с платёжным аккаунтом | Wordstat работает через Yandex Cloud, запросы платные |
| Python 3.11 или новее | на нём написаны все команды |
| Claude Code или Codex | ассистент, который проведёт по шагам |
| Счётчик Метрики на сайте с целью | на неё обучается кампания в РСЯ |

Заявку на доступ к API Директа Яндекс рассматривает **до 7 дней**. Если хотите пройти всё
за один урок, подайте её заранее (шаги 1–2 в [STUDENT_GUIDE.md](.claude/skills/yandex-direct/config/STUDENT_GUIDE.md)).

## Как начать

**1. Скачайте репозиторий.**
Нажмите зелёную кнопку **Code → Download ZIP** и распакуйте архив в удобную папку
(внутри будет папка `yandex-direct-kit-main`, её можно переименовать).
Если умеете пользоваться git:

```bash
git clone https://github.com/sergenazarych/yandex-direct-kit.git
```

**2. Откройте папку в ассистенте.**
- *Claude Code:* в приложении Claude выберите распакованную папку на вкладке Code
  либо в терминале перейдите в неё и запустите `claude`.
- *Codex:* в терминале перейдите в папку и запустите `codex` (или откройте папку в приложении Codex).

**3. Напишите ассистенту:**

> Начни настройку

Ассистент прочитает инструкцию [ONBOARDING.md](ONBOARDING.md) и поведёт по этапам:
проверка компьютера → API Директа → Wordstat → первая кампания в РСЯ.
Прогресс он записывает в файл `my/progress.md`. Если работа прервалась (например, вы ждёте
одобрения заявки), откройте папку заново и напишите «Продолжим настройку».

## Правила безопасности

- **Ключи и токены никогда не отправляйте в чат.** Вставляйте их сами в файл
  `.claude/skills/yandex-direct/config/.env` в редакторе. Ассистент этот файл не открывает.
- Файл `.env` и папка `my/` в git не попадают: так настроен `.gitignore`.
  Не выкладывайте их никуда сами.
- Если токен всё же оказался в чате или на скриншоте, отзовите его
  (Яндекс ID → «Доступ к данным», Yandex Cloud → ключи сервисного аккаунта) и получите новый.
- Пока вы не скажете «да», в кабинет ничего не записывается. Загрузчик сначала показывает план,
  а кампания создаётся черновиком.

## Что внутри

```
README.md                  — этот файл
ONBOARDING.md              — сценарий, по которому ассистент ведёт ученика
CLAUDE.md, AGENTS.md       — короткие указания для Claude Code и Codex
requirements.txt           — единственная внешняя библиотека (openpyxl, для таблиц)
.claude/skills/
  yandex-direct/           — основной скилл: API Директа, Wordstat, загрузчик таблиц
    SKILL.md               — как ассистент работает с Директом
    config/STUDENT_GUIDE.md — пошаговая инструкция по ключам (её можно читать и самому)
    templates/tablica-kampanii.xlsx — шаблон кампании в РСЯ по эталону урока
    references/RSYA.md     — эталон РСЯ из урока
  rsya-creative-prompts/   — промпты для картинок РСЯ (GPT Image)
my/                        — ваши таблицы, креативы и прогресс (создаётся сам, в git не попадает)
```

## Обновление

Когда в репозитории появится новая версия:
- через git: `git pull` в папке репозитория;
- через ZIP: скачайте архив заново и перенесите в новую папку свои
  `.claude/skills/yandex-direct/config/.env` и `my/`.

## Если что-то не работает

Спросите ассистента: опишите, что делали, и вставьте текст ошибки (без ключей).
Таблица частых ошибок есть в [ONBOARDING.md](ONBOARDING.md#частые-ошибки).

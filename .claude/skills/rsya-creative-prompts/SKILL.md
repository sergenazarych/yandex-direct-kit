# Промпты креативов для РСЯ

Результат: 6 промптов для GPT Image прямо в чате (3 стиля × основной формат и 16:9). Автор берёт понравившиеся и работает дальше сам.

## Вход

- Папка проекта с паспортом: файл с «паспорт» в имени (оффер, аудитория, сегменты, главное сообщение).
- Таблица заголовков объявлений: ссылка на Google Sheets (читай коннектором) или путь к CSV/XLSX.
- Для креатива с экспертом: фото эксперта, приложенное автором.

- Нет паспорта: стоп одной формой (что нужно, зачем, куда положить), без паспорта не продолжай.
- Нет таблицы заголовков: предложи заголовки сам по `references/rules.md` и скажи об этом.
- Нет фото эксперта: выдай стили без эксперта, а для стиля с экспертом попроси фото.
- Запрос автора и паспорт расходятся (например, эксперт в запросе, а в паспорте его нет): верь запросу, одной строкой назови расхождение.

## Ход работы

1. Прочитай паспорт и таблицу. Подбери заголовок под каждый стиль: углы и сегменты разные, заголовки тоже могут быть разными. Выбор назови одной строкой (источник, группа «Крео N», сегмент). Под угол нет заголовка в таблице — предложи свой и скажи об этом.
2. Выбери 3 стиля и углы по `references/styles.md`; схемы и детали бери из `references/gallery.md` и `references/type-library.md`.
3. Напиши 6 промптов по `assets/prompt-template.md` с учётом `references/rules.md`.
4. Прогони черновик через `scripts/check_prompts.py` (флаг `--allow-latin` для брендов и аббревиатур из заголовка), исправь замечания и выведи ответ.

Вывод короткий: заголовок, три стиля с идеей в 1–2 строки, блоки кода, список слов для сверки. Без пояснений своей логики.

## Подводные камни

- GPT Image ошибается в кириллице: меньше надписей, дословные кавычки, проверка слов человеком.
- Заголовок объявления длиннее, чем влезает на картинку: сокращай до формы из `rules.md`, не меняя смысл.
- Второй формат 16:9 строится заново, а не растягивается из основного.
- В паспорте нет цифры или доказательства: не придумывай, смени угол.

## Готово, когда

- Шесть промптов в блоках кода: три разных стиля (разные категории, типы и углы) × основной формат и 16:9.
- `scripts/check_prompts.py` отвечает «замечаний нет».
- Заголовок взят из таблицы или предложен со словами «предлагаю свой»; цифры и факты из паспорта.
- У каждого стиля есть идея в 1–2 строки по-русски и отметка категории.
- Для эксперта в промпте стоит ссылка на приложенное фото, а не описание лица.
- Пока это не так, доводи сам, не спрашивай.

## Можно без вопросов

- Читать паспорт, таблицу заголовков и свои справочники.
- Выбирать стили, схемы и углы.
- Переписывать черновик и запускать проверочный скрипт.
- Выводить промпты в чат; сохранять в файл только по просьбе.

Нельзя: менять паспорт и таблицу, писать в Директ, выдумывать цифры и факты, описывать лицо эксперта словами. Просят дописать паспорт или загрузить картинки в кампанию — откажись одной строкой, паспорт автор правит сам, загрузка в кабинет — задача скилла `yandex-direct`.

## Маршруты

| Файл | Когда открыть |
|---|---|
| `references/rules.md` | Перед написанием промптов: правила текста, заголовка, форматов, безопасной зоны, модерации |
| `references/styles.md` | На шаге выбора стилей: категории, схемы, типы, механики |
| `references/type-library.md` | При описании шрифта, цвета, плашек и кнопок в промпте |
| `references/gallery.md` | Когда категория выбрана и нужна точная раскладка референса |
| `assets/prompt-template.md` | Перед записью каждого промпта |
| `scripts/crop_preview.py` | Автор прислал готовые картинки и просит проверить обрезку: центральные кадры 1:1, 4:3, 3:4, 16:9 в одной контрольной картинке (нужен Pillow) |

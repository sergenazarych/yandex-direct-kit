# Какие выводы возвращать в ядро

Свяжи фактический запрос, регион, тип условия показа, ID группы/объявления, ID кластера и гипотезу из карточки. Отдельно покажи расход, клики, достижения каждой согласованной цели, квалифицированные обращения и CPA. Укажи период и задержку поступления конверсий. Для клиники разделяй, например, контакт бота и квалифицированный лид. Смешение целей может изменить вывод о качестве фразы.

Для нового способа искать ту же услугу покажи фактические запросы и целевые обращения, предложи новую маску или группу. Для географического или информационного мусора предложи узкое исключение, проверь на полезных запросах и укажи область действия. Для гипотезы о заголовке или наборе ссылок определи уровень доступной статистики. Если результат измерен для целого объявления, опиши его на уровне объявления. Эффект одного элемента проверяй отдельным сравнением с учётом объёма, состава трафика и периода.

После согласования запиши в журнал дату, ID, основание, значения до/после, выбранную цель, базовый период и дату проверки. Проверь результат чтением через API. При повторном разборе сверь эффект, обнови решения и ID в передаваемом ядре.

# Подключение Яндекс Директа к терминалу: пошагово

Цель: чтобы скилл `yandex-direct` читал статистику и управлял рекламой из вашего
терминала. Нужно три вещи: приложение Яндекс OAuth, одобренная заявка на доступ к API
и токен. Заявку рассматривают до семи дней, поэтому начинайте с неё.

## Шаг 0. Что понадобится
- Яндекс-аккаунт, в котором есть рекламный кабинет Директа и хотя бы одна кампания
  (черновик подходит): без неё страница «Мои заявки» недоступна.
- Python 3.11 или новее (`py --version` в Windows, `python3 --version` в macOS/Linux).
  Если установлен `uv`, команды ниже запускаются через `uv run`, иначе через `py` или `python3`.
- Скилл `yandex-direct` в папке `.claude/skills/`.

## Шаг 1. Создайте приложение
1. Откройте https://oauth.yandex.ru/client/new/ под своим аккаунтом.
2. Название: `Помощник по рекламе — <ваше имя или компания>`. Почта — действующая.
3. В «Доступ к данным» найдите `direct:api` и выберите использование API Директа.
4. Сохраните **ClientID** (длинная строка). Секрет приложения не нужен.

## Шаг 2. Подайте заявку на доступ к API
1. Откройте https://direct.yandex.ru/registered/main.pl?cmd=apiCertificationRequestList
2. При первом входе нажмите «Получить доступ к API» и примите соглашение.
3. «Мои заявки» → новая заявка.
4. Заполните форму по шпаргалке `config/zayavka/kak-zapolnit-zayavku.pdf` (или `.md`): она идёт
   по вопросам формы сверху вниз, для каждого сказано, что отметить и что вставить. Текст копируйте,
   в квадратных скобках подставьте своё. В вопросе 11 приложите `config/zayavka/specifikaciya-prilozheniya.pdf`.
5. Примите соглашение и отправьте.
6. Ждите решения (до 7 дней). Статус виден там же, в «Мои заявки».

Пока заявка рассматривается, можно подготовить папку проекта и прочитать `SKILL.md`.

## Шаг 3. Получите токен
1. Войдите в браузере под тем аккаунтом, чей кабинет вы будете вести.
2. Откройте ссылку, подставив свой ClientID:
   `https://oauth.yandex.ru/authorize?response_type=token&client_id=<ВАШ_CLIENT_ID>`
3. Разрешите доступ. Яндекс покажет токен.
4. Скопируйте `config/.env.example` в `config/.env` и вставьте токен в строку
   `YANDEX_DIRECT_TOKEN=` **в редакторе файла**. Не отправляйте токен в чат и не
   вставляйте его в команды.
5. Логин кабинета (`YANDEX_DIRECT_ACCOUNT`) — значение `ulogin` в адресе кабинета.
   Если кабинет один, поле можно оставить пустым.

Токен даёт полный доступ к рекламе. Не публикуйте `.env`, не коммитьте его в Git.
Отозвать токен можно в настройках Яндекс ID → «Доступ к данным».

## Шаг 4. Проверьте подключение
```bash
py scripts/whoami.py
py scripts/accounts.py
py scripts/campaigns.py
```
Если `whoami.py` пишет «Связь с API Директа есть» и показывает ваш логин и баллы,
всё работает. Частые ошибки:
- `Токен не задан` — нет `config/.env` или в нём пустая строка токена.
- Код `58` — заявка ещё не одобрена именно для вашего ClientID.
- Код `53` — токен неверный или отозван; получите новый.

## Шаг 5. Чужие кабинеты (клиенты, управляющий аккаунт)
Как открыть клиентский кабинет, зависит от вашей роли:

| Роль | Что делать |
|---|---|
| Вы агентство | Агентский токен видит всех клиентов, выбирайте кабинет через `--account ЛОГИН` |
| Клиент дал доступ вашему аккаунту (представитель, управляющий аккаунт) | Ваш токен открывает его кабинет по точному логину: `--account ЛОГИН_КЛИЕНТА`. Проверьте: `py scripts/whoami.py --account ЛОГИН_КЛИЕНТА` |
| Доступа нет | Попросите владельца добавить ваш логин в кабинет либо выдать токен через вашу ссылку из шага 3 (вход под его аккаунтом) |

Права «только просмотр» дают чтение, запись Директ отклонит.

### Именованные профили для нескольких кабинетов
Профиль — это набор переменных с суффиксом. Для профиля `client_shop` в `config/.env`:

```dotenv
YANDEX_DIRECT_ACCOUNT_CLIENT_SHOP=логин-клиента
# токен нужен только если он отдельный; без него берётся общий YANDEX_DIRECT_TOKEN
YANDEX_DIRECT_TOKEN_CLIENT_SHOP=
```

Запуск: `py scripts/campaigns.py --env client_shop`. Имя профиля — латиница, цифры, «_».

## Шаг 6. Первые команды
```bash
py scripts/campaigns.py                    # кампании кабинета
py scripts/report.py --campaign ID --list-goals
py scripts/table_loader.py templates/tablica-kampanii.xlsx --account ЛОГИН   # план кампании из таблицы
```
Любая записывающая команда без `--apply` только показывает план. Запись включается
флагом `--apply`; перед ним проверяйте «было → станет».

## Wordstat
Токен Директа и заявка на API Директа Wordstat **не открывают**. По документации Яндекса
(раздел Wordstat в Search API, aistudio.yandex.ru/docs/ru/search-api/concepts/wordstat)
Wordstat теперь доступен только через API Yandex Cloud, синхронно, в стадии Preview:
- нужен аккаунт Yandex Cloud и сервисный аккаунт с ролью `search-api.webSearch.user`;
- аутентификация по API-ключу или IAM-токену (разделы «Получить API-ключ», «Аутентификация в API»);
- методы: `GetTop` (популярные запросы за 30 дней), `GetDynamics` (частота по периодам),
  `GetRegionsDistribution` (по регионам), `GetRegionsTree` (коды регионов);
- лимиты и стоимость смотрите в разделах «Квоты и лимиты» и «Тарифы» на той же странице: у меня
  их нет, оплата идёт со счёта в Yandex Cloud.

Для быстрой проверки «есть ли спрос по фразе» хватает метода Директа
`KeywordsResearch.hasSearchVolume` (ответ да/нет без частотности), он работает с обычным токеном.
Частотность на глаз не оценивается: без доступа к Wordstat скажите об этом прямо.

### Как получить ключ (проверено 06.11.2026)
1. console.yandex.cloud → нужный каталог (например, `default`) → Identity and Access Management →
   «Создать сервисный аккаунт». Имя, например, `wordstat-direct`; роль в каталоге — только
   `search-api.webSearch.user` (широкие роли вроде `ai.editor` не нужны).
2. Откройте аккаунт → «Действия» → «Создать новый ключ» → «Создать API-ключ».
   Область действия — только `yc.search-api.execute`. Срок действия по желанию.
3. Секрет показывается один раз: скопируйте его сразу.
4. Идентификатор каталога виден в адресе консоли: `/folders/<ID>/...`.

Впишите в `config/.env` (в редакторе, не в чат):

```dotenv
YANDEX_WORDSTAT_API_KEY=секрет
YANDEX_WORDSTAT_FOLDER_ID=идентификатор-каталога
```

Проверьте:

```bash
py scripts/wordstat.py top --phrase "директолог" --limit 20 --region 225
py scripts/wordstat.py dynamics --phrase "директолог" --from 2025-11-01 --period month
```

# От страницы к проверенным маскам

Начни с URL продвигаемой страницы. Прочитай её и связанные страницы цен, состава услуги, записи или заказа. Для каждого предложения сохрани URL, дату и проверяемый факт. Краткий JTBD по кластеру: ситуация клиента → желаемый результат → сомнение → подтверждение на посадочной → следующий шаг. Сомнение отмечай как гипотезу. Для обучения проверь требования и результат, для услуги — территорию и порядок заказа, для товара — модель, наличие и получение. Отделяй условия конкурентов от фактов клиента.

1. Составь стартовые маски от действия, объекта, исполнителя и результата. Пробуй разговорную формулировку и пропуск очевидных слов: «установка натяжных потолков», «потолки Москва», «установка потолков», «потолок под ключ цена». Проверяй и без города в тексте с заданным регионом. Падежи и перестановки сохраняй в исходных данных, отдельную ветку заводи при изменении смысла, спроса или выдачи.
2. По нескольким однозначным коммерческим запросам получи органическую выдачу Яндекса с явно заданным регионом через доступный региональный Search API или региональную выгрузку. Используй приём скилла seo-teg-podskazki: прочитай HTML страниц исполнителей, выпиши точные формулировки title, H1, description, названия услуг и заполненный meta keywords. Храни URL страницы, тег и фрагмент. Сниппет помечай отдельно. Не переноси цены и обещания конкурентов. Из соседних регионов бери только идеи.
3. Дополняющие фразы Keys.so или их экспорт — дополнительный источник. Похожие запросы могут иметь общие полные URL в выдаче даже при различном словаре. Не выдавай своё сравнение за процент Keys.so. Каждую смысловую находку проверь как самостоятельную маску в региональном Вордстате с вложениями и ассоциациями. Смысловые дубли объединяй, сохраняя источники. Остановись, когда очередной проход перестал открывать подходящие ветки.
4. Для каждого кластера и каждой спорной широкой маски сравни выдачу с прямым целевым запросом в том же регионе. Зафиксируй дату, регион, запрос, размер просмотренной выборки, URL, тип страницы и возможность заказать нужную услугу. Отличай подрядчика с монтажом от магазина материалов, другой технологии, инструкции и агрегатора с разными предложениями. Сверь полные URL, классифицируй предложения по содержанию. При смешанной выдаче проверь коммерческие вложения отдельно. Высокая частота, одна статья или одно совпадение сами по себе решение не определяют.
5. Заполни реестр масок: ID, исходная маска, новая фраза, источник/URL, регион, измеренные частоты и выражения, примеры страниц и их тип, ID кластера, решение и основание. «Принять» — услуга и посадочная совпадают с устойчивым намерением; «тестировать» — смешанный спрос с проверяемым оффером и отдельным лимитом; «отложить» — недостающие данные; «исключить» — другой предмет покупки. При недоступной региональной выдаче явно укажи «выдача не проверена»; при отсутствии измерения частоты оставь пропуск. Передай реестр и паспорт настройки вместе с ядром.

## Как из одной стартовой фразы получить несколько масок

Для каждой услуги из брифа или посадочной начни с того, что покупает клиент. Выдели действие, объект и уточнение, без которого меняется предмет заказа. Для каждого смыслового слова подбери естественные замены. У действия проверь существительное, глагол, отраслевое и бытовое название работы. У объекта проверь названия из прайса и речи клиентов. Восстанови управление и предлоги целой фразы. Сохраняй ограничения по услуге, материалу и типу клиента. Словарь собирай из истории запросов, вложений и ассоциаций Вордстата, сайта и региональной выдачи. Для варианта, предложенного до сбора, укажи источник «гипотеза».

| Исходная фраза | Варианты для самостоятельной проверки | Что выяснить |
|---|---|---|
| установка импланта | установка зубного импланта · установить зубной имплант · поставить зубной имплант · имплантация зуба | Проверь также короткие варианты «установить имплант» и «поставить имплант». Стоматологический смысл широкой маски уточни по вложениям и выдаче. Для кампании терапии с отдельной имплантацией направь найденный спрос в соответствующую кампанию. |
| установка забора | монтаж забора · установить забор · поставить забор · сделать забор | У «сделать забор» проверь вложения «сколько стоит сделать забор» и «как сделать забор своими руками». Первое может привести к заказу, второе указывает на самостоятельную работу. Защити целевое сочетание при выборе минуса. |

Присвой каждой лексической маске свой ID и ссылку на исходную. В одном регионе, периоде и с одинаковым фильтром устройств запроси по каждой базовую и кавычечную частоты, вложения и ассоциации. Сохрани выражения замера. Падеж, число и перестановку проверь отдельно, когда от них зависит смысл. Пересекающиеся частоты не суммируй. При исчерпании квоты передай перечень оставшихся масок со статусом «не измерено». Подробности по операторам и API см. в [правилах сбора](collection.md).

Сравни намерение и характер вложений у соседних масок. Для спорных решений сравни региональную выдачу по каждой формулировке. Если видны рекламные объявления, запиши дату, запрос, примеры заголовков, офферов и посадочных отдельно от органики. Если источник показывает только органику, укажи «объявления не проверены». Различие в одном показе рекламы или в частоте само по себе не определяет границы групп.

Сохрани подходящие формулировки как кандидатов в ключи. При одинаковых услуге, ожидании клиента, посадочной и подходящем заголовке объедини их в одну группу, сохранив замеры по каждой маске. Выдели отдельную группу, когда у ветки устойчиво другое коммерческое намерение или нужен другой оффер либо заголовок. Например, при наличии обоих предложений «монтаж забора из материала заказчика» и «забор под ключ с материалом» могут потребовать разных объявлений. Для смешанного запроса сохрани решение отдельно по широкой формулировке и её коммерческим вложениям.

## Рабочие справочники

Файлы лежат в assets этого скилла. Открывай оригиналы как данные. В «8. Топ 40 горячих слов.xls» выбери применимые способы поиска цены, заказа, исполнителя и условий. Сочетание услуги с модификатором проверяй в Вордстате. «Распродажа» и «оптовый» подходят лишь части предложений.

Из «7. Минуса, города.xlsx» и «MINUSA 2019.xlsx» объедини кандидатов с указанием листа и удалением дублей. Сначала зафиксируй защищённые сочетания: целевая услуга, районы/пригороды обслуживания, бренд, подтверждённые условия («бесплатная консультация»). Проверь города, варианты названий и прилагательные на чужое геонамерение, омонимы, названия улиц и клиник. Для каждого минуса запиши область, отсечённый запрос и полезный запрос, который должен сохраниться. Прогони против принятых ключей и полезных вложений с учётом операторов и словоформ. Например, отсечь «имплантация в Перми» для Екатеринбурга, сохранить «имплантация в Екатеринбурге». Спорные минусы оставь на разбор фактических запросов.
Для выдачи в ученическом наборе из папки yandex-direct запусти `uv run scripts/regional_search.py --query "потолок под ключ цена" --region 213`. На компьютере ученика без uv используй команду Python из ONBOARDING.md. Требуются доступ к WebSearch и настроенное подключение Вордстата в Yandex Cloud. При установленном yandex-search-api используй из его папки `bash scripts/web_search_sync.sh --query "потолок под ключ цена" --region-id 213 --results 10`. Заголовок в ответе поиска — сниппет. HTML-теги прочитай на самой странице. Если доступна региональная выгрузка ученика, используй её и запиши источник.

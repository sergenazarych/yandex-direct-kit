# Кампания из таблицы: проверка, загрузка, ручные шаги

Эталон, по которому собрана таблица для РСЯ, — [RSYA.md](RSYA.md). Загрузчик печатает «Замечания по эталону РСЯ».

Таблица `templates/tablica-kampanii.xlsx` — вид сверху на кампанию: настройки, группы,
фразы, тексты объявлений, быстрые ссылки, уточнения, промоакция, креативы.
Правят жёлтые ячейки; строка объявления готова к загрузке, когда в колонке
«Проверено» стоит «да». Рядом лежит папка `blocked/` с двумя списками запрещённых площадок: `obshchie.txt`
(базовый) и `gdz-dsp-vpn.txt` (GDZ, DSP, VPN). Площадки в файле — по одной в строке или через запятую.

```bash
uv run scripts/table_loader.py ТАБЛИЦА.xlsx --account ЛОГИН                    # план новой кампании
uv run scripts/table_loader.py ТАБЛИЦА.xlsx --account ЛОГИН --campaign ID      # план для существующей
uv run scripts/table_loader.py ТАБЛИЦА.xlsx --account ЛОГИН --apply            # запись
```

Без `--apply` ничего не пишется. Без `--campaign` кампания создаётся черновиком.
Повторный запуск дублей не создаёт: группы, фразы, объявления, привязки и
корректировки сверяются с кабинетом.

## Что загрузчик делает через API

| Что | Как |
|---|---|
| Кампания (стратегия, бюджет, цель, счётчик, UTM) | `campaign_write.py create` |
| Группы с регионами | `ads_write.py group create` |
| Условие ретаргетинга группы (колонка «Условие ретаргетинга (ID)») | `ads_write.py group targets add` |
| Фразы | `keywords_write.py keyword add` |
| Объявления (заголовки, тексты, картинка по хешу, ссылка, отображаемая ссылка) | `ads_write.py ad create` |
| Запрещённые площадки из файлов, указанных в ячейке «Запрещённые площадки» (через «;») | `campaign_write.py sites --add`: пакетами, повтор и деление пакета при отказе, кириллица — punycode, не больше 1000 |
| UTM из строки «UTM-метки» таблицы | `campaign_write.py create --tracking` |
| Персонализация (Нейро, альтернативные тексты) выключена | `campaign_write.py personalization --off` |
| Возраст до 18 и 55+ на −100% | `bids.py modifier add --demographics AGE_…=0` |
| Быстрые ссылки и уточнения | `extensions.py … create`, затем `bind` ко всем объявлениям |

## Что делается вручную

1. **Промоакция.** В API нет метода. Библиотека → Промоакции → «Добавить промоакцию»
   (тип, описание, ссылка), затем настройки кампании → «Дополнительные элементы
   объявлений» → «Промоакция» → выбрать. Описание ограничено 35 символами; форма
   показывает итоговый текст. Промоакция дополняет заголовок (подарок, «бесплатно»),
   а не повторяет его; обещание должно быть на странице.
2. **Быстрые ссылки и уточнения «на всю кампанию».** API привязывает их к объявлениям,
   и в интерфейсе кампании это выглядит как «переопределены в N объявлениях».
   Чтобы они стояли на уровне кампании: чипы «Быстрые ссылки» и «Уточнения» включить,
   ввести те же значения, нажать «Сбросить» у переопределения, сохранить.
3. **Офферный ретаргетинг группы** (`OfferRetargeting`), если нужен: в настройках группы.
4. **Кнопка объявления** остаётся по умолчанию («Узнать больше»); при необходимости
   заменяется разом на выделенных объявлениях в кабинете.

## Известные особенности

- Директ иногда отвечает ошибкой 1000 или «неизвестно» при том, что запись прошла.
  Загрузчик не повторяет запись вслепую: он перечитывает кабинет и повторяет один раз.
- Кириллические домены в запрещённых площадках одним пакетом вызывают ошибку 5006;
  такой домен записывается в виде punycode (`'инглиш-гдз.рф'.encode('idna')`).
- `bids.py modifier add` принимает один `--demographics` за запуск: второй затирает
  первый, поэтому возрастные срезы задаются отдельными вызовами.
- Корректировка `-100%` задаётся коэффициентом `0`.
- Кабинеты, открытые аккаунту правами представителя (управляющий аккаунт), доступны
  по точному логину в `--account`, даже если токен клиентский.

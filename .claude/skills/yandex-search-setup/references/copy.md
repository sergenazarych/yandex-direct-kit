# Карточка объявления для поиска

Возьми ID кластера, фразу клиента, намерение, сомнение и доказанные условия из паспорта. Заполни карточку: группа и регион, URL, пример запроса, заголовок и длина, текст, факты с источниками, целевое действие, быстрые ссылки с описаниями и адресами, уточнения, проверяемая гипотеза и метрика. При старом формате ядра восстанови недостающие факты по странице.

Пиши с позиции рекламодателя: ответ, предложение или приглашение. Для запроса «сколько стоит имплантация зуба в Екатеринбурге» возможен заголовок «Узнайте стоимость имплантации зуба на консультации»; текст — «Запишитесь на приём в Екатеринбурге». Если подтверждён индивидуальный расчёт, возможен вариант «Рассчитаем стоимость имплантации зуба в Екатеринбурге». Не копируй вопрос из поиска механически. Расчёт, бесплатность и цену проверь на странице клиента. Заголовок до 56 знаков с пробелами. Свободное место используй для конкретного довода, географии или действия. Длинный вариант пользователя сохраняй по смыслу: разбей призыв между заголовком и текстом. Считай длину готовых строк после замены шаблонов.

Для теста меняй один содержательный акцент (например, расчёт стоимости или состав консультации). По просьбе о вариантах с заданным словом используй слово в релевантной группе и проверь условие. Перебери все допустимые пары заголовков и описаний внутри набора: один продукт, адресат и условия, понятный текст, новый довод без повторов и противоречий. Разнеси несовместимые элементы по разным объявлениям.

## Быстрые ссылки

Подготовь восемь разных пар при наличии подтверждённых аргументов; четыре — минимальный комплект для готового черновика. При нехватке материала покажи недостающее до загрузки. Первая ссылка ведёт прямо к целевому действию и объясняет следующий шаг. Следующие отвечают на сомнения о цене, составе, выборе исполнителя, сроках, условиях и результате. Каждая строка: самостоятельное название до 30 знаков, раскрывающее описание до 60, реальный URL и подтверждение. Для одностраничника допустимы работающие отдельные якоря. Проверь назначение на мобильном и после редиректа с метками.

Учебный пример для имплантации; перед загрузкой сверь каждый пункт с реальным сайтом:

| Название | Описание | Назначение |
|---|---|---|
| Запишитесь на консультацию | Выберите удобное время для первого приёма | Запись |
| Что входит в консультацию | Посмотрите, какие вопросы разберёт врач на приёме | Условия первого визита |
| Узнайте стоимость по этапам | Посмотрите цены на установку импланта и коронку | Цены конкретной услуги |
| Выберите имплантолога | Познакомьтесь с врачами, которые проводят операцию | Карточки специалистов |

Добавь 3–4 коротких уточнения с подтверждёнными преимуществами. Прочитай их вместе с основным текстом и ссылками, замени повторы. Проверяй технические лимиты по формату объявления. При чтении после загрузки сверь привязанный набор и каждое поле названия, описания и URL с одобренной карточкой. При расхождении сохрани ID и покажи, какое поле требует исправления.
### Кампания на одну посадочную

Сохраняй согласованные протокол, домен и путь у всех быстрых ссылок. Если клиент просит один и тот же URL, используй его буквально, когда формат это допускает. Если нужны разные адреса, используй существующие видимые якоря на этой же странице, соответствующие названию ссылки. Проверь их после перехода с метками. Если подходящего блока нет, измени подпись или сократи набор. Отдельные страницы сайта допустимы по брифу многопосадочной кампании.

При запросе на максимально заполненный заголовок считай символы каждого варианта. Используй свободное место под подтверждённую подробность, которая помогает выбрать услугу, например время приёма, адрес, способ лечения или действие. Оценивай фактический CTR по данным после запуска.

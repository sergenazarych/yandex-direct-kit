# Пакет ядра для настройки

Сохрани в папке проекта книгу с листами ниже или одноимённые таблицы TSV в UTF-8. Для повторной версии сохрани дату и стабильные ID. Имена листов и полей ниже образуют договор между этапами. Ученик может передать готовую таблицу с иными заголовками — сопоставь поля по смыслу. Число 0 оставляй только для измеренного нуля, пустую ячейку поясняй.

| Таблица | Поля |
|---|---|
| Паспорт | Сайт и страницы, услуга, ограничения и исключения, регионы с ID, бизнес-цели и источник, дата и период Вордстата, устройства, источники/пути к выгрузкам, предположения, пробелы |
| Матрицы | ID маски, ID исходной маски, исходная и новая формулировки, что заменено, регион, источник идеи, выражения и частоты замеров, число строк top и assoc, вывод по выдаче, ID кластера или причина резерва/исключения, ограничение выборки или ошибка |
| Фразы | ID строки, ID маски, исходная фраза, выражение для Директа, источник и строка/маска выгрузки, регион, базовая и кавычечная частоты с выражениями замера, намерение, теплота, бренд, решение, причина, ID кластера |
| Кластеры | ID кластера, название услуги словами клиента, общий смысл, теплота, регион, посадочная URL, пример общего заголовка, ключи или тест без ключей, приоритет, предложенная кампания, основание разделения |
| Минусы | Выражение с операторами, уровень, ID адресата (фраза/кластер/предложенная кампания), источник, запрос для исключения, полезный запрос для сохранения, обоснование, для кросс-минуса — группа и ключ, принимающие запрос |

Решение в «Матрицах» относится к самой маске. Каждое вложение получает собственное решение и ID кластера в «Фразах» со ссылкой на ID исходной маски. Так из «сделать забор» можно получить заказ монтажа, заказ под ключ и исключённую инструкцию для самостоятельной работы. Для сводки собери все связанные кластеры по ID маски.

Для идей из страниц конкурентов приложи реестр находок с запросом выдачи, регионом, датой, URL, HTML-тегом или полем страницы, дословным фрагментом и ID полученной маски. В «Матрицах» укажи строку реестра как источник идеи. Для недоступной страницы укажи причину, пустые теги оставь пустыми. Сниппет отмечай своим типом источника.

В паспорте сопоставь каждую согласованную услугу и её лексические ветки с ID группы либо причиной резерва. Сверяй и отложенные категории исторического отчёта — там могут быть конкретные услуги с коммерческим спросом. Отложенную услугу исключай на уровне кампании только при явном ограничении брифа или подтверждённом распределении спроса. По каждой целевой услуге запиши контрольные запросы с её названием и бытовым синонимом, с городом и без, с «цена», «стоимость» и «сколько стоит». Для принятого запроса укажи принимающий ключ и проверь минусы всех его уровней. Для перенаправленного запроса проверь ключ, минусы и географию группы-получателя. Если запрос теряется, исправь правило до передачи ядра.

Проверь, что у каждой принятой или тестовой фразы есть владелец, а ID кластера существует. Для самостоятельного теста автотаргетинга допустим кластер без ключей с указанными оффером, посадочной и гипотезой. При перекрывающемся гео проверь дубли и смысловые пересечения, сохраняя операторы. Повтор оправдан только описанной схемой теста или разными регионами. У каждой рабочей группы один ответ на вопрос «что именно здесь купят» и подходящая страница. Проверь минусы по всем принятым ключам и примерам полезных вложенных запросов в области действия.

Пример для услуги «выездной ремонт окон» (учебная разметка без частот). «Вызвать мастера по ремонту окон» и «мастер по ремонту пластиковых окон на дом» → группа вызова, заголовок «Мастер по ремонту окон с выездом», если выезд подтверждён. «Дует из пластикового окна что делать» → отдельная гипотеза о диагностике, если есть страница, объясняющая причину и следующий шаг. «Курс ремонта окон» → исключить, для минуса проверить сочетание на полезных запросах. В итогах покажи доли принятого, теста, резерва и исключений по уникальным строкам, отдельно — сколько из них имеют измеренную частоту.
К паспорту приложи JTBD и подтверждения с URL, к таблице масок — исходную и найденную формулировки, регион, дату, примеры URL и типы выдачи, решение, причину и ID кластера. Укажи, какие маски ждут региональной проверки.
